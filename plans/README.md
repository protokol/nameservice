  loading is CJS-coupled; blast radius far exceeds the benefit for a stable
  plugin suite. Packages keep `main: dist/index` CJS output.
- **Unlocking `@arkecosystem/*` from 3.0.0 → 3.13.0**: three years of lockfile
  drift would mix its failures into the package-manager migration. Plans pin
  ARK packages to exact `3.0.0` for an atomic swap; the bump remains an
  optional, unplanned follow-up (registry shows the 3.x line alive at
  3.13.0 and a 4.0.0-next line exists).
- **TypeScript 7 (native compiler)**: the repo needs `emitDecoratorMetadata`
  + legacy decorators for ARK core-kernel DI; that stack is not proven under
  ts-jest with the TS 7 native build. Toolchain targets TS 5.9.
- **ESLint 10**: typescript-eslint 8 support matrix is safest on ESLint 9;
  the flat-config conversion in plan 002 makes the later jump trivial.
- **joi 17 → 18 / typeorm upgrades / any ARK-internal dependency bumps**:
  owned by ARK core 3.x itself (they ship as transitive deps); do not bump here.
